# docs/wireframes/

This directory holds visual wireframe assets referenced from docs/wireframe-notes.md.

Place image files and source design files here. Recommended structure:

- docs/wireframes/desktop/
  - landing-hero-v1.png
  - dashboard-empty-v1.png
- docs/wireframes/mobile/
  - landing-hero-mobile-v1.png

Naming: <screen>-<state>-v1.<ext>
Include a small text file or caption for each image describing the intended interaction and user story mapping.

Example: add a matching caption file landing-hero-v1.txt with "Maps to: US#1; Designer: @designer-anna"
